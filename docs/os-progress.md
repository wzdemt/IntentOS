**B. 后台服务**

- [x] `service.list` 看电脑里有哪些后台服务在跑
- [x] `service.info` 看某个服务是不是开机自动启动
- [x] `service.control` 启动 / 停止 / 重启某个后台服务 ★首批

**C. 计划任务**

- [x] `task.list` 看电脑里设了哪些定时任务
- [x] `task.info` 看某个定时任务的详细配置
- [x] `task.create` 新建一个定时任务
- [x] `task.delete` 删掉一个定时任务
- [x] `task.control` 让定时任务马上跑一次

**D. 电源**

- [x] `power.shutdown` 关机 / 重启 / 注销（最高危） ★首批
- [x] `power.lock` 立刻锁屏 ★首批
- [x] `power.sleep` 休眠
- [x] `power.plan` 看/换电源计划
- [x] `power.battery` 看电池电量、是不是插着电

**E. 事件日志**

- [x] `event.channels` 看系统里都有哪几本「日志本」
- [x] `event.query` 按时间、级别、编号查系统事件日志 ★首批
- [x] `event.clear` 清空某本日志（等于抹证据）

**F. 系统信息**

- [x] `system.info` 看这台电脑是什么系统、什么版本
- [x] `system.hardware` 看 CPU 型号、几个核、主频多少
- [x]  内存总量/可用/占用
- [x] `system.uptime` 看这台电脑开机多久了
- [x] `system.load` 看整台电脑此刻 CPU 忙不忙
- [x] `disk.list` 看有几个盘 ★首批
- [x] `display.info` 看屏幕分辨率

**G. 环境变量**

- [x] `env.get` 进程级
- [x] `env.set` 用户级

**H. 系统配置**

- [x] `registry.read` 读注册表里的配置项
- [x] `registry.write` 写注册表配置项
- [x] `startup.list` 一次性看到「这台电脑开机都自动启动…
- [x] `time.zones` 看时区、改时区（改系统时间更敏感）
